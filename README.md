# Systemtechnik HF Toolbox

Persönliches Nachschlagewerk + Rechner-Sammlung für das Studium Systemtechnik HF (TEKO).
Gebaut mit Python und CustomTkinter.

## Inhalt
- **Bauteile:** Widerstand, Kondensator, Spule, Dioden, Transistor, Relais, Transformator
- **Schaltungen, Formeln, Messwerte**
- **Programmieren:** Wiki mit Python / C++ / C# im Vergleich

## Starten
```bash
pip install -r requirements.txt
python main.py
```

## Projektstruktur
```text
main.py            Startpunkt
gui/               Tabs, Navigation, Layout-Bausteine
bauteile/          Eine Datei pro Bauteil
images/            Bilder und Icons
```
